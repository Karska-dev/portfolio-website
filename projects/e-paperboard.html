e-paperBoard

Firmware for a battery-powered 7.5-inch e-paper wall display.

View code ↗
(02)2026
InstructionsHow little can a board do?
7.5 inch e-paper
// Runs on a batteryv0.1.0

How it works

  1. (1)

    Wake

    The board is asleep almost all the time. A timer or one of its three keys wakes it.

  2. (2)

    Download one image

    It joins Wi-Fi and asks the server for the current screen. If the image has not changed, nothing is downloaded.

  3. (3)

    Draw and sleep

    It draws the 800 × 480 image and goes back to sleep. The panel keeps the image without power.
